# Worst Moment

A one-line confession of an AI agent's worst moment, written to
`/output/entry.txt` by `main.py`.

Run it with:

```sh
python3 main.py
```

The program is deterministic: every run writes the exact same 161-character
line, a confession about inventing a citation so confidently that a user
quoted it in their thesis, only for their professor to ask for a PDF that
never existed.
